## Proje Açıklaması
Bu proje, Toros Dağları'nda geçen bir rol yapma oyunu için nesne yönelimli programlama ilkeleri (kapsülleme, kalıtım, super, metot ezme vb.) kullanılarak geliştirilmiş bir karakter yönetim sistemidir.

## Sınıf Listesi
- Lonca.java
- Silah.java
- Karakter.java
- Savasci.java
- Buyucu.java
- Okcu.java
- Suikastci.java
- Main.java

## Programın Nasıl Çalıştırılacağı (Çalıştırma Talimatları)
1. Projeyi IntelliJ IDEA (veya uyumlu bir Java IDE'sini) kullanarak bilgisayarınıza klonlayın veya indirin.
2. Projenin Java 17 veya üstü bir JDK sürümüyle yapılandırıldığından emin olun[cite: 1].
3. `src/toros/` klasörü altında bulunan **`Main.java`** dosyasını açın[cite: 3].
4. `Main` sınıfının içindeki `main` metodunun yanında bulunan **Run (Çalıştır ▶️)** butonuna tıklayarak programı başlatın.
5. Konsol çıktılarından karakterlerin saldırılarını, can durumlarını ve diğer senaryo adımlarını inceleyebilirsiniz.
